# Reportar una vulnerabilidad

La seguridad de comercios y clientes es esencial. No reportes vulnerabilidades, secretos o datos de pago en issues públicos.

Usa la opción de reporte privado de seguridad de GitHub si está habilitada para este repositorio. Si no aparece, contacta en privado al mantenedor desde su perfil de GitHub e incluye una descripción breve, impacto, pasos seguros para reproducir y una forma de responderte.

No incluyas datos de clientes, números de tarjeta, credenciales, tokens o archivos de producción. No realices pruebas contra sistemas de proveedores o comercios sin autorización expresa.

El mantenedor confirmará recepción, coordinará la evaluación y acordará divulgación responsable cuando exista una ruta segura para corregir y comunicar el problema. Este proyecto aún no opera servicios productivos ni tiene un SLA de seguridad.
