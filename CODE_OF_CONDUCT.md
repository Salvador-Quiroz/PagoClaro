# Código de conducta

PagoClaro busca una comunidad profesional, respetuosa y segura para todas las personas, con independencia de su origen, identidad, idioma, capacidad, experiencia o situación económica.

Esperamos comunicación respetuosa, crítica enfocada en el trabajo, apertura a correcciones, reconocimiento de fuentes y cuidado al manejar información sensible. No se toleran acoso, discriminación, amenazas, ataques personales, divulgación de datos privados ni conducta que intimide o excluya a participantes.

Las personas responsables del proyecto pueden editar o retirar contenido, cerrar discusiones y restringir participación cuando sea necesario para detener una conducta dañina. Para reportar un incidente, contacta en privado al mantenedor del repositorio; no publiques información personal ni detalles de seguridad en un issue público.

Este código se aplica a issues, pull requests, revisiones, documentación y cualquier espacio comunitario administrado por el proyecto.
