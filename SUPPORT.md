# Soporte

Este repositorio se encuentra en etapa de cimientos y todavía no ofrece un servicio de pagos en producción.

- Usa GitHub Issues para preguntas sobre documentación o propuestas de producto.
- Usa issues de tipo bug solo para comportamiento reproducible del software publicado.
- Para temas de cuenta, cobros o datos personales de un comercio no compartas información privada en público; en esta etapa no existe un canal de soporte comercial.
- Para vulnerabilidades, sigue el proceso privado de SECURITY.md.

No envíes datos bancarios, documentos de identidad, información de tarjetas, contraseñas ni datos de clientes.
